MXLSHOP — เวอร์ชันเซิร์ฟเวอร์ (วิธีติดตั้งบน Windows)
=====================================================

หน้าตาและเมนูเหมือนเวอร์ชันทดสอบทุกอย่าง แต่ข้อมูลทั้งหมดอยู่บนโน๊ตบุ๊คเครื่องนี้
ลูกค้าทุกคนเห็นสินค้า/สต็อกตรงกัน สลิปและออเดอร์เข้าหลังบ้านคุณจริง
ส่วนการเช็กรหัสผ่าน ตัดเครดิต สุ่มรางวัล และใช้โค้ดส่วนลด ทำบนเซิร์ฟเวอร์ ลูกค้าแอบแก้ไม่ได้


1) ติดตั้ง (ทำครั้งเดียว)
------------------------
1. ติดตั้ง Node.js เวอร์ชัน LTS จาก https://nodejs.org (กด Next ไปเรื่อย ๆ)
2. แตกไฟล์ ZIP นี้ไปไว้ที่ C:\mxlshop  (ชื่อโฟลเดอร์ไม่ต้องมีภาษาไทยหรือเว้นวรรค)
3. ดับเบิลคลิก start.bat จะเห็นหน้าต่างดำ ข้อความ "MXLSHOP server running"
4. ครั้งแรกจะแสดง "FIRST-TIME ADMIN LOGIN" พร้อมรหัสผ่านแอดมินที่ระบบสุ่มให้
   (บันทึกไว้ในไฟล์ data\FIRST-ADMIN-PASSWORD.txt ด้วย)
5. เปิดเบราว์เซอร์ไปที่ http://localhost:3000 แล้วเข้าสู่ระบบด้วย
      ชื่อ: adminmxl     รหัสผ่าน: (ตามที่แสดงในหน้าต่างดำ)
6. กดชื่อของคุณบนแถบเมนู > เปลี่ยนรหัสผ่านใหม่ทันที (10 ตัวขึ้นไป) แล้วลบไฟล์ FIRST-ADMIN-PASSWORD.txt
   ลืมรหัสผ่านแอดมิน: ปิดหน้าต่างเซิร์ฟเวอร์ แล้วดับเบิลคลิก reset-admin.bat

อย่าปิดหน้าต่างดำ start.bat ขณะเปิดร้าน (ย่อหน้าต่างได้) ถ้าเซิร์ฟเวอร์ล้ม มันจะเริ่มใหม่เองใน 5 วินาที


2) ย้ายข้อมูลจากเวอร์ชันทดสอบ (ถ้ามี)
-------------------------------------
1. ในเวอร์ชันทดสอบเดิม: หลังบ้าน > ข้อมูล/สำรอง > ดาวน์โหลดไฟล์สำรอง (หรือกด "คัดลอกข้อมูลสำรอง")
2. ในเวอร์ชันใหม่: หลังบ้าน > ข้อมูล/สำรอง > "กู้คืนจากไฟล์" (หรือวางข้อความแล้วกด "กู้คืนจากข้อความ")
   - สินค้า หมวดหมู่ แบนเนอร์ รางวัล โค้ด ช่องทางชำระเงิน สมาชิกและเครดิต ถูกนำมาทั้งหมด
   - รหัสผ่านสมาชิกเดิมใช้ได้ ระบบอัปเกรดการเข้ารหัสให้เองเมื่อเขาล็อกอินครั้งแรก
   - รหัสแอดมินจะกลับไปเป็นรหัสของเวอร์ชันเดิม ให้เปลี่ยนใหม่ทันทีหลังกู้คืน
   - ไฟล์เพลงไม่ถูกย้าย ให้อัปโหลดใหม่ที่ตั้งค่าเว็บ
   - การกู้คืนเขียนทับข้อมูลปัจจุบัน (ระบบเก็บสำเนาก่อนกู้ไว้ใน data\backups ให้)
เวอร์ชันนี้เริ่มต้นด้วยเกมสุ่ม/เหรียญที่ "ยังไม่มีรางวัล" เพื่อไม่ให้แจกเครดิตโดยไม่ตั้งใจ


3) ตั้งค่าก่อนเปิดขาย
---------------------
- หลังบ้าน > ช่องทางชำระเงิน: ใส่เลขบัญชี/พร้อมเพย์/วอเล็ท
- หลังบ้าน > สินค้า: เพิ่มสินค้าและสต็อก, ตั้งค่าอื่น ๆ ตามต้องการ
- ทดลองสมัครสมาชิกอีกเบราว์เซอร์ (หรือโหมดไม่ระบุตัวตน) เพื่อดูว่าฝั่งลูกค้าเห็นตรงกับที่ตั้งไว้


4) เปิดให้คนนอกเข้า ด้วย Cloudflare Tunnel (ไม่ต้องเปิดพอร์ตที่เราเตอร์)
---------------------------------------------------------------------
เซิร์ฟเวอร์ฟังเฉพาะในเครื่องนี้ (localhost) คนนอกเข้าได้ผ่านอุโมงค์ของ Cloudflare ซึ่งให้ HTTPS ฟรี

ก) ทดลองเร็ว ๆ (ไม่ต้องมีโดเมน ลิงก์เปลี่ยนทุกครั้งที่เปิดใหม่):
   1. เปิด PowerShell พิมพ์:  winget install --id Cloudflare.cloudflared
   2. ปิดแล้วเปิด PowerShell ใหม่ พิมพ์:  cloudflared tunnel --url http://localhost:3000
   3. จะได้ลิงก์ https://xxxx.trycloudflare.com ส่งให้เพื่อนลองเปิดได้

ข) ใช้งานจริง (ต้องมีโดเมน ประมาณ 300-500 บาท/ปี):
   1. สมัคร Cloudflare (ฟรี) แล้วเพิ่มโดเมนของคุณ ตามขั้นตอนที่เว็บบอก (เปลี่ยน Nameserver ที่ผู้ขายโดเมน)
   2. ใน Cloudflare ไปที่ Zero Trust > Networks > Tunnels > Create a tunnel (ชนิด Cloudflared)
   3. เลือก Windows แล้วคัดลอกคำสั่งติดตั้ง (cloudflared service install ...) ไปรันใน PowerShell แบบ Administrator
   4. ที่แท็บ Public hostname: ใส่ shop.โดเมนของคุณ  / Service: HTTP  / URL: localhost:3000
   5. เปิด https://shop.โดเมนของคุณ ได้เลย (cloudflared จะทำงานเป็น service เริ่มเองทุกครั้งที่เปิดเครื่อง)
   (ชื่อเมนูใน Cloudflare อาจเปลี่ยนเล็กน้อยตามเวลา ดูคู่มือ Cloudflare Tunnel ประกอบได้)


5) ให้รันเองหลังเปิดเครื่อง และไม่ดับ
------------------------------------
- กด Win+R พิมพ์ shell:startup แล้ว Enter จากนั้นสร้าง Shortcut ของ start.bat ไว้ในโฟลเดอร์นั้น
- ตั้งค่า Windows: Settings > System > Power > Screen and sleep ให้ Sleep = Never (ตอนเสียบปลั๊ก)
- ปิดฝาโน๊ตบุ๊คแล้วไม่ให้หลับ: Control Panel > Power Options > Choose what closing the lid does > Do nothing
- ตั้ง Active hours ของ Windows Update เพื่อไม่ให้รีสตาร์ทกลางวัน
- แนะนำให้ใช้ UPS หรือแบตเตอรี่โน๊ตบุ๊คช่วยตอนไฟดับสั้น ๆ และต่อสาย LAN แทน Wi-Fi ถ้าทำได้


6) สำรองข้อมูล (สำคัญมาก)
------------------------
- ระบบสำรอง db.json อัตโนมัติทุกวัน เก็บ 14 วันล่าสุดที่ data\backups  แต่อยู่เครื่องเดียวกัน ถ้าเครื่องเสียก็หายด้วย
- ดับเบิลคลิก backup.bat เพื่อคัดลอก data + uploads ไปที่ ..\mxlshop-backup\วันที่-เวลา
  แล้วคัดลอกโฟลเดอร์นั้นไปแฟลชไดรฟ์หรือคลาวด์อย่างน้อยสัปดาห์ละครั้ง
- กู้คืนทั้งระบบ: ปิดเซิร์ฟเวอร์ แล้ววางโฟลเดอร์ data และ uploads จากสำรองกลับเข้าไป จากนั้นเปิด start.bat
- รูปภาพ/สลิปอยู่ในโฟลเดอร์ uploads ข้อมูลสมาชิก เครดิต ออเดอร์อยู่ใน data\db.json


7) ความปลอดภัยที่ระบบทำให้ และสิ่งที่คุณต้องทำเอง
------------------------------------------------
ระบบทำให้แล้ว: เข้ารหัสรหัสผ่านแบบ scrypt, จำกัดการลองรหัสผิด, ตัดเครดิต/สุ่มรางวัล/ใช้โค้ดบนเซิร์ฟเวอร์,
กันซื้อสต็อกชิ้นสุดท้ายซ้อนกัน, ซ่อนรหัสสินค้าและรางวัลจากลูกค้า, ลูกค้าเห็นเฉพาะข้อมูลของตัวเอง
คุณต้องทำเอง:
- ตั้งรหัสแอดมินให้ยาวและไม่ซ้ำที่อื่น อย่าแชร์รหัสแอดมินให้ใคร
- อย่าแชร์โฟลเดอร์ data (มีข้อมูลสมาชิกและรหัสผ่านที่เข้ารหัสแล้ว แต่ไม่ควรหลุดออกไป)
- อัปเดต Windows และใช้โปรแกรมป้องกันไวรัส
- ตรวจสลิปและซองของขวัญก่อนกดอนุมัติเสมอ ระบบนี้ยังไม่ตรวจสลิปหรือรับซองให้อัตโนมัติ
- ระบบไม่มีอีเมลรีเซ็ตรหัส สมาชิกลืมรหัส ให้แอดมินกด "ตั้งรหัสใหม่" ที่แท็บสมาชิก
- ถ้าเก็บข้อมูลส่วนบุคคลของลูกค้า (ที่อยู่ เบอร์โทร) ควรแจ้งนโยบายความเป็นส่วนตัวในหน้าร้านด้วย


8) ข้อจำกัดที่ควรรู้
-------------------
- ข้อมูลเก็บเป็นไฟล์ JSON เหมาะกับสมาชิกระดับร้อยถึงหลักพันคน ถ้าโตกว่านี้ควรย้ายไปฐานข้อมูลจริง
- เครื่องเดียวคือจุดเสี่ยงเดียว ถ้าเครื่องดับหรือเน็ตหลุด ร้านก็ปิด (ข้อมูลไม่หาย แต่ลูกค้าเข้าไม่ได้)
- ทดสอบโค้ดเซิร์ฟเวอร์บน Node.js 22 แล้ว (ระบบอื่นต้องใช้ Node 18 ขึ้นไป)


9) แก้ปัญหาเบื้องต้น
-------------------
- เปิดแล้วหน้าขาว: กด Ctrl+F5
- "Port already in use": มีโปรแกรมอื่นใช้พอร์ต 3000 แก้ที่ start.bat โดยลบ rem หน้าบรรทัด set PORT=3000 แล้วเปลี่ยนเลข
  (ถ้าใช้ Cloudflare Tunnel ต้องเปลี่ยนพอร์ตในตัว tunnel ให้ตรงกันด้วย)
- อยากทดสอบจากมือถือในวง Wi-Fi เดียวกัน: ใน start.bat เพิ่มบรรทัด  set HOST=0.0.0.0  แล้วเปิด http://IPของโน๊ตบุ๊ค:3000
  (ทดสอบเสร็จควรเอาออก)
- เซิร์ฟเวอร์ปิดเอง: ดูข้อความสีแดงในหน้าต่างดำ แล้วส่งให้คนช่วยดู
